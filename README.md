# hunain-humail-webapp

Personal profile website of **Hunain Humail**: software engineer building with AI, fintech and open finance. Includes a built-in CMS (`/admin`).

Live site: [https://hunain-humail-webapp.web.app](https://hunain-humail-webapp.web.app)

Built AI-natively: the code is generated by Cursor agents driven by the prompts, rules, agents and skills in [`AGENTS.md`](AGENTS.md) and [`.cursor/`](.cursor).

Stack: Next.js · TypeScript · Tailwind · GSAP/Lenis · Framer Motion · Firebase · Vitest · Playwright.

Firebase project `hunain-humail-webapp` (Spark). Firestore `(default)` is in `me-central1`. Hosting serves the static export in `out/`. Security rules and collection shapes: [`docs/firebase.md`](docs/firebase.md).

## Setup

```bash
npm ci
cp .env.example .env.local
```

Fill the six `NEXT_PUBLIC_FIREBASE_*` keys in `.env.local` from the Firebase web app config. `.env.local` is gitignored. `NEXT_PUBLIC_SITE_URL` is already `https://hunain-humail-webapp.web.app`. The public site still builds from seed data when those keys are empty.

## Emulators

```bash
npm run emulators
```

Auth `:9099`, Firestore `:8080`, Storage `:9199`, emulator UI `:4000`. For local CMS work, set `NEXT_PUBLIC_USE_FIREBASE_EMULATOR=true` in `.env.local`. Rules tests: `npm run test:rules` (uses project `demo-hunain-humail`, not production).

## Seed

Published pages read Firestore at build time and fall back to `src/lib/seed` when a collection is empty or the read fails.

There is no service account in this setup. Sign in at `/admin` with the admin Google account, then use **Import seed data** on the dashboard. That write is admin-only and an idempotent upsert of `profile`, `settings`, `story`, `now`, `work`, and `writing`.

`npm run seed` is optional and only for the emulator or a machine that already has `GOOGLE_APPLICATION_CREDENTIALS`.

## Deploy

Storage is not enabled on the Spark plan. `storage.rules` stays in the repo and is not a deploy target.

```bash
npm run build:static
firebase deploy --only hosting,firestore --project hunain-humail-webapp --non-interactive
```

`firebase.json` hosting `public` is `out/`, with `cleanUrls`, `trailingSlash: false` (same as `next.config.ts`), an `/admin/**` rewrite to `/admin.html`, and a long cache on `/_next/static/**`. `predeploy` runs `npm run build:static`.
