# hunain-humail-webapp

Personal profile website of **Hunain Humail**: software engineer building with AI, fintech and open finance. Includes a built-in CMS (`/admin`) and a terminal CMS CLI (`npm run cms`). See [`docs/cms-cli.md`](docs/cms-cli.md).

Live site: [https://hunain-humail-webapp.web.app](https://hunain-humail-webapp.web.app)

Built AI-natively: the code is generated by Cursor agents driven by the prompts, rules, agents and skills in [`AGENTS.md`](AGENTS.md) and [`.cursor/`](.cursor).

Stack: Next.js · TypeScript · Tailwind · GSAP/Lenis · Framer Motion · Firebase · Vitest · Playwright.

Firebase project `hunain-humail-webapp` (Spark). Firestore `(default)` is in `me-central1`. Hosting serves the static export in `out/`. Security rules and collection shapes: [`docs/firebase.md`](docs/firebase.md).

## Setup

```bash
npm ci
cp .env.example .env.local
```

Fill the six `NEXT_PUBLIC_FIREBASE_*` keys in `.env.local` from the Firebase web app config. `.env.local` is gitignored. `NEXT_PUBLIC_SITE_URL` is already `https://hunain-humail-webapp.web.app`. The public site still builds from seed data when those keys are empty.

## Emulators

```bash
npm run emulators
```

Auth `:9099`, Firestore `:8080`, Storage `:9199`, emulator UI `:4000`. For local CMS work, set `NEXT_PUBLIC_USE_FIREBASE_EMULATOR=true` in `.env.local`. Rules tests: `npm run test:rules` (uses project `demo-hunain-humail`, not production).

## Seed

Published pages read Firestore at build time and fall back to `src/lib/seed` when a collection is empty or the read fails.

There is no service account in this setup. Sign in at `/admin` with the admin Google account, then use **Import seed data** on the dashboard — or run `npm run cms -- seed` after `npm run cms -- login`. Both writes are admin-only and an idempotent upsert of `profile`, `settings`, `story`, `now`, `work`, and `writing`. See [`docs/cms-cli.md`](docs/cms-cli.md).

`npm run seed` is optional and only for the emulator or a machine that already has `GOOGLE_APPLICATION_CREDENTIALS`.

## Deploy

Storage is not enabled on the Spark plan. `storage.rules` stays in the repo and is not a deploy target.

```bash
npm run build:static
firebase deploy --only hosting,firestore --project hunain-humail-webapp --non-interactive
```

`firebase.json` hosting `public` is `out/`, with `cleanUrls`, `trailingSlash: false` (same as `next.config.ts`), an `/admin/**` rewrite to `/admin.html`, and a long cache on `/_next/static/**`. `predeploy` runs `npm run build:static`.

## App Check / reCAPTCHA Enterprise (required for the live blueprint)

`generateBlueprint` runs with `enforceAppCheck: true`. Every request needs a valid App Check token, or the site shows "Security check failed".

Required config:
1. **reCAPTCHA Enterprise key.** In Google Cloud console (project `hunain-humail-webapp`), go to Security → reCAPTCHA → Create key.
   - Platform: Website. Type: score-based (no checkbox challenge).
   - Domains: `hunain-humail-webapp.web.app`, `hunain-humail-webapp.firebaseapp.com`, plus your custom domain and `localhost` if needed.
   - The key must live in this same GCP project.
2. **App Check registration.** In the Firebase console, go to App Check → Apps → web app `1:7489717436:web:b0daf969739310dfae7cb9` → reCAPTCHA Enterprise.
   - Paste the **same** site key.
   - Token TTL: 1 hour is fine.
3. **Env.** Set `NEXT_PUBLIC_RECAPTCHA_ENTERPRISE_SITE_KEY` in `.env.local` to that key, then rebuild and run `firebase deploy --only hosting`. The key is baked into the static build.
4. **Enforcement.** Cloud Functions is enforced in code (`enforceAppCheck: true`). Turn on enforcement in the console only after the App Check metrics show mostly verified requests.

Verify:
- `node scripts/check-build-env.mjs` must print `ok`. It also runs automatically as `prebuild`. It fails on missing env vars or when Google answers "Invalid site key" or "Invalid domain for site key".
- In the browser DevTools Network tab, while generating a wireframe:
  - `recaptcha/enterprise/reload` → 200
  - `content-firebaseappcheck.googleapis.com/...:exchangeRecaptchaEnterpriseToken` → 200
  - the `generateBlueprint` request carries an `X-Firebase-AppCheck` header
- Function logs should show `"app":"VALID"`.

To skip the check (CI without secrets): `SKIP_ENV_CHECK=1`. To skip only the online key check: `SKIP_RECAPTCHA_CHECK=1`.
